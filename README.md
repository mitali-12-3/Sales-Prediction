<h1 align="center" id="title">Sales Prediction</h1>

<p align="center"><img src="https://github.com/user-attachments/assets/99ef415f-e7eb-46b5-aea0-944cc2daa760" alt="project-image"></p>

<p id="description">The sales prediction model built using XGBoost demonstrated high accuracy in forecasting Walmart's weekly sales trends. The evaluation metrics such as Root Mean Square Error (RMSE) and R-squared indicated the model's ability to capture complex patterns and dependencies within the dataset. The XGBoost model outperformed the baseline Random Forest Regressor achieving an improved prediction accuracy of approximately 85%. Additionally feature importance analysis revealed key drivers of sales such as holiday indicators store IDs and past sales trends. These results validate the robustness and applicability of the XGBoost model in real-world sales forecasting scenarios.</p>
