<p id="description">The sales prediction model built using XGBoost demonstrated high accuracy in forecasting Walmart's weekly sales trends. The evaluation metrics such as Root Mean Square Error (RMSE) and R-squared indicated the model's ability to capture complex patterns and dependencies within the dataset. The XGBoost model outperformed the baseline Random Forest Regressor achieving an improved prediction accuracy of approximately 85%. Additionally feature importance analysis revealed key drivers of sales such as holiday indicators store IDs and past sales trends. These results validate the robustness and applicability of the XGBoost model in real-world sales forecasting scenarios.</p>![Screenshot 2025-02-09 134623](https://github.com/user-attachments/assets/56b09b8b-731a-4e3b-b2c8-4249a839aaf6)
